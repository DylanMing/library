
Vim是一个非常经典的文本编辑器，在服务器中经常预装，也可以在命令行中使用，因为学会vim命令是非常重要的。不知道有没有进了vim不知道怎么退ctrl+c按倒爆的经历。

首先，vim有三种模式：

- **命令模式**：所有输入都被识别成命令

- **编辑模式**：用于编辑文本

- **末行模式**：输入多个字符的命令

三种模式的切换来进行文本编辑，保存退出等操作

# 打开文件

| 命令                   | 说明                                    |
| ---------------------- | --------------------------------------- |
| vim filename           | 打开或新建一个文件，光标首行首部        |
| vim -r filename        | 恢复上次vim打开时崩溃的文件             |
| vim -R filename        | 只读打开                                |
| vim + filename         | 打开文件，光标尾行首部                  |
| vi +n filename         | 打开文件，光标n行首部                   |
| vi +/pattern filename  | 打开文件，光标第一个与pattern匹配的位置 |
| vi -c command filename | 文件编辑前执行命令                      |

# 光标移动

在**命令模式**下可以进行光标的移动：

上下左右单格移动

- `h`：将光标向左移动一个字符。

- `j`：将光标向下移动一行。

- `k`：将光标向上移动一行。

- `l`：将光标向右移动一个字符。

行级别移动

- `G` ： 将光标移动到文件末行
- `gg`：将光标移动到文件首行
- `数字g` : 移动到第g行
- `0`：将光标移动到当前行的开头。
- `$`：将光标移动到当前行的末尾。

单词级别移动

- `w`：将光标移动到下一个单词的开头

- `e`：将光标移动到当前单词的末尾。

- `b`：将光标移动到上一个单词的开头。

- `<ctrl>+o` 跳转回之前的位置

- `<ctrl>+i` 返回跳转之前的位置

- `H` ：光标移至屏幕顶行

- `M` ：光标移至屏幕中间行

- `L` ：光标移至屏幕最后行

# 编辑基本命令

以下是一些基本的Vim命令：

- `i`：在当前光标位置插入文本，**使用后进入编辑模式**

- `x`：删除当前光标所在位置的字符，**使用后进入编辑模式**

- `dd` : 删除当前行

- `yy`：复制当前行。

- `p`：粘贴已复制或删除的文本。

- `u`：撤销上一次操作。

- `Ctrl-r`：重做上一次操作。

- `r`：替换当前光标所在位置的字符。

- `c`：删除从当前光标位置到指定位置的文本并进入插入模式。

- `v`：进入可视模式，选择文本。

- `:s/<old>/<new>/g`：将当前行中的`<old>`替换为`<new>`。

- `:%s/<old>/<new>/g`：将整个文件中的`<old>`替换为`<new>`。

- `Esc`：**退出插入模式。**

- `Ctrl-h`：删除光标左侧的字符。

- `Ctrl-w`：删除光标左侧的单词。

- `Ctrl-u`：删除当前行的所有文本。

- `Ctrl-a`：插入文本到行首。

- `Ctrl-e`：插入文本到行尾。

- `Ctrl-t`：插入一个制表符。

# 退出保存命令

在末行模式下进行，通过 `:` 表示进入末行模式

- `:w`：保存文件。

- `:q`：退出Vim编辑器。

- `:q!`：强制退出Vim编辑器，不保存文件。

- `:wq`：保存文件并退出Vim编辑器。

# 宏命令

宏是一种将多个操作序列记录并重复执行的方法。以下是一些宏命令：

- `qa`：开始录制宏并将其存储在寄存器`a`中。

- `q`：停止录制宏。

- `@a`：执行存储在寄存器`a`中的宏。

- `@@`：重复上一次执行的宏。

# 分屏命令

Vim可以在窗口中分屏显示文件。以下是一些分屏命令：

- `:sp`：水平分屏当前窗口。

- `:vsp`：垂直分屏当前窗口。

- `Ctrl-w h`：将光标移到左侧窗口。

- `Ctrl-w j`：将光标移到下方窗口。

- `Ctrl-w k`：将光标移到上方窗口。

- `Ctrl-w l`：将光标移到右侧窗口。

- `Ctrl-w +`：增加当前窗口的高度。

- `Ctrl-w -`：减小当前窗口的高度。

# 其他命令

以下是一些其他常用的Vim命令：

- `:set number`：显示行号。

- `:set nonumber`：隐藏行号。

- `:set expandtab`：使用空格代替制表符。

- `:set tabstop=4`：设置制表符宽度为4个字符。

- `:set hlsearch`：高亮显示搜索结果。

- `:set nohlsearch`：取消高亮显示搜索结果。

- `:set background=dark`：将背景设置为暗色。

- `:set background=light`：将背景设置为亮色。
