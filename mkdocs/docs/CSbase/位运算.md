# 什么是位运算
位运算，就是符号位共同参与的运算，计算机对二进制数据进行的运算都叫位运算。
它一般用于底层开发（算法设计、驱动、图像处理、单片机等），

```c
int a = 35;
int b = 47;
int c = a + b;
```

计算机内部会进行二进制数据的相加


```
35:  0 0 1 0 0 0 1 1
47:  0 0 1 0 1 1 1 1
————————————————————
82:  0 1 0 1 0 0 1 0
```

所以使用位运算可以显著提高代码在机器上的执行效率。


# 位运算符

| 符号           | 描述 | 运算规则                                  |
| -------------- | ---- | ----------------------------------------- |
| `&`            | 与   | 两个相应位都为1时，结果才为1              |
| <code>\|<code> | 或   | 两个相应位都为0时，结果才为0              |
| `^`            | 异或 | 两个相应位相同为0，相异为1                |
| `~`            | 取反 | 0变1，1变0                                |
| `<<`           | 左移 | 各二进位全部左移若干位，高位丢弃，低位补0 |
| `>>`               | 右移     | 各二进位全部右移若干位，高位补0，有符号数，补符号位或补0                                          |

# 位运算判断奇偶

可以使用位运算符判断奇数偶数，非常快，只需要将目标值和1进行&操作即可，因为二进制的奇数末位为1，偶数末位为0


一个简单判断奇偶的函数

```python
def odd_or_even(number):
	if number&1:
		print("odd")
	else:
		print("even")
```
