
# win命令行设置代理

临时生效，仅在当前终端生效
```bash
set HTTP_PROXY=http://127.0.0.1:10809
set HTTPS_PROXY=http://127.0.0.1:10809

set http_proxy=socks5://127.0.0.1:10808
set https_proxy=socks5://127.0.0.1:10808
```

python设置代理
```python
import os
os.environ["HTTP_PROXY"] = "http://127.0.0.1:33210"
os.environ["HTTPS_PROXY"] = "http://127.0.0.1:33210"

```

# ip地址

IPv4地址协议中预留了3个IP地址段，作为私有地址，供组织机构内部使用。也就是说这些ip地址属于内网ip，是内网中才能看到的ip地址

- A类地址：10.0.0.0--10.255.255.255  
- B类地址：172.16.0.0--172.31.255.255 
- C类地址：192.168.0.0--192.168.255.255

而总的IP地址范围：1.0.0.1——255.255.255.254

使用这些IP一定是你在公司或学校内网中，比如公司路由下。
比如 `10.130.104.15` 就是一个内网的地址

# 路由器设置

## DHCP服务器
DHCP服务器可以自动给局域网中的设备分配IP,子网掩码等TCP/IP协议参数。DHCP服务器分别由三种状态，分别为开，关和自动，
DHCP服务器控制一段IP地址范围，客户机登录服务器就可以自动获得服务器分配的IP地址和子网掩码，担任DHCP服务器的计算机需要安装TCP/IP协议，并设置为静态IP地址，子网掩码，默认网关等

## 路由器应用

### AP隔离
access point 隔离， 在wifi网络中无线路由器或热点将连接的设备之间进行隔离，无法相互通信

### 虚拟服务器
虚拟服务器：路由器通过开放指定的端口，在保证内网安全的前提下实现互联网对指定端口的内网服务器的访问
- 常用服务器：常用服务器下拉列表中列举了一些常用的服务，您可以从中选择所需要的服务。
- 外部端口：路由器提供给广域网的服务端口。您可以输入一个端口号，也可以输入一个端口段，如：6001-6008。
- 内部端口：路由器提供给局域网的服务端口。如果内部端口与服务端口相同，您可以留空（或者填0），或者输入一个具体端口号，如：80。
- IP地址：局域网中作为服务器的计算机的IP地址。
- 协议：服务器所使用的协议。

如果您的FTP服务器（端口号为21）IP地址为192.168.1.2，这时您可以指定如下的虚拟服务器规则：

| 常用服务器 | 外部端口 | 内部端口 | IP地址        | 协议  |
| ----- | ---- | ---- | ----------- | --- |
| FTP   | 21   | 21   | 192.168.1.2 | ALL |

也就是说 假如路由器的公网地址是x，内部某台连接路由器的机器固定的子网ip地址为y，那么虚拟服务器就得转发就是
x:21--->y:21

所有连接到路由器21端口的流量都会转发到该设备的21
