# 题目描述
给定一个*未排序*的整数数组 `nums` ，找出*数字连续的最长序列*（不要求序列元素在原数组中连续）的**长度**。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。
**示例 1：**

> **输入：** nums = [100,4,200,1,3,2]
> **输出：** 4
> **解释：** 最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。

**示例 2：**

> **输入：** nums = [0,3,7,2,5,8,4,6,0,1]
> **输出：** 9
> 解释： 最长数字连续序列是 [0,1,2,3,4,5,6,7,8] 长度为9

**提示：**

- `0 <= nums.length <= 105`
- `-109 <= nums[i] <= 109`

首先未排序，其实可以试试先排序，
其次有重复数值，可以试试set()
# 解法1 暴力循环遍历

## 思路
遍历set，将每个连续序列长度和已有的最长序列长度对比，保留更长的

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        max_l = 0
        nums = set(nums) # 去重
        for j in nums:
            if j+1 in nums:# 如果连续数在set中
                l = 1
                while j+1 in nums:
                    l += 1
                    j += 1
                max_l = max(l,max_l)
        return max_l
```

但是这样超出时间限制了，问题在于，判定条件是连续序列的开始，`if j+1 in nums` 表示连续序列中的下一个数是否在set中，
而这样对于中间的数其实都会跑一遍if里的循环，实际上只需要找到子序列开头即可，因此需要更改判断条件使得找到的是序列开头，因此 `if j-1 not in nums:` 

比如上面的例子，只需要判定最长的子序列的开头，即0就行，因此 if 的条件应该设置为 `if j-a not in nums:`

此时时间复杂度是 `0（n）` , 如果没有重复数字，那么for循环会遍历n次（n是list长度），因此这个循环的时间复杂度是 `O(n)`，while循环最坏会执行n次，但是集合查找的时间复杂度为`O(1)` ,不是主要影响因素


```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        max_l = 0
        nums = set(nums)
        for j in nums:
            if j-1 not in nums:
                l = 1
                while j+1 in nums:
                    l += 1
                    j += 1
                max_l = max(l,max_l)
        return max_l
```


## java

```
class Solution {

    public int longestConsecutive(int[] nums) {

        int res = 0;    // 记录最长连续序列的长度

        Set<Integer> numSet = new HashSet<>();  // 记录所有的数值

        for(int num: nums){

            numSet.add(num);    // 将数组中的值加入哈希表中

        }

        int seqLen;     // 连续序列的长度

        for(int num: numSet){

            // 如果当前的数是一个连续序列的起点，统计这个连续序列的长度

            if(!numSet.contains(num - 1)){

                seqLen = 1;

                while(numSet.contains(++num))seqLen++;  // 不断查找连续序列，直到num的下一个数不存在于数组中

                res = Math.max(res, seqLen);    // 更新最长连续序列长度

            }

        }

        return res;

    }

}


```

# 解法2 并查集

## 思路

将每个数字看成一个节点，连接的关系就是数值比它大1，那么问题转变成满足条件的构建的最大树额节点个数

## python

在下面代码里，构建的字典`fa`就是树，初始化的root的key，value都是nums里元素本身，size储存各个树的节点数量。

**定义并查集模板**，*（合并，查找集）*
**查找函数**：查看元素`x`是否是自己的根节点，如果`x`不是根节点，就更新根节点。然后返回找到的根节点
**合并函数**：元素f和to是否在同一个根节点上，如果不在同一个根节点上就将f的根节点指向to的根节点，然后更新size里储存的节点数量

主函数遍历数组，如果当前元素的下一个元素存在于fa的root里，那么就将其合并，最后给出最大size

```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        nums = set(nums) #去重
        ans = 0

        ###并查集模版：
        #此处值是离散的，使用字典
        fa = {num: num for num in nums} #储存每个节点的root，初始化为自己
        size = {num : 1 for num in nums} #储存以当前节点为root的节点数量
                                    #初始化只有自己一个节点
        def find(x):
            if fa[x] != x:
                fa[x] = find(fa[x])
            return fa[x]
        def merge(f, to):
            f = find(f)
            to = find(to)
            if f != to :
                fa[f] = to
                size[to] += size[f]

        #遍历数组，当满足合并关系时，做merge，最后取最大值即题解
        for num in nums:
            if num + 1 in fa:
                merge(num, num+1)
        if size:
            ans = max(size.values())
        return ans


```
