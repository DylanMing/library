# 题目描述

给你一个字符串 `croakOfFrogs`，它表示不同青蛙发出的蛙鸣声（字符串 `"croak"` ）的组合。由于同一时间可以有多只青蛙呱呱作响，所以 `croakOfFrogs` 中会混合多个 `“croak”` _。_

请你返回模拟字符串中所有蛙鸣所需不同青蛙的最少数目。

要想发出蛙鸣 "croak"，青蛙必须 **依序** 输出 `‘c’, ’r’, ’o’, ’a’, ’k’` 这 5 个字母。如果没有输出全部五个字母，那么它就不会发出声音。如果字符串 `croakOfFrogs` 不是由若干有效的 "croak" 字符混合而成，请返回 `-1` 。

**示例 1：**

**输入：** croakOfFrogs = "croakcroak"
**输出：** 1 
**解释：** 一只青蛙 “呱呱” 两次

**示例 2：**

**输入：** croakOfFrogs = "crcoakroak"
**输出：** 2 
**解释：** 最少需要两只青蛙，“呱呱” 声用黑体标注
第一只青蛙 "**cr**c**oak**roak"
第二只青蛙 "cr**c**oak**roak**"

**示例 3：**

**输入：** croakOfFrogs = "croakcrook"
**输出：**-1
**解释：** 给出的字符串不是 "croak" 的有效组合。

**提示：**

-   `1 <= croakOfFrogs.length <= 105`
-   字符串中的字符只有 `'c'`, `'r'`, `'o'`, `'a'` 或者 `'k'`





# 解法 1

## 思路

<!-- 这里可写通用的实现逻辑 -->
维护 croak 的个数，如果遇到当前字母，如果完全正确，则肯定是由前面字母过来，当前字母加1，前面字母数减 1。比如遇到 r，则必是 `c->r`，所以r加1， c 减 1。

k 代表结尾，表示一次喊叫结束，所以遇到 c 的时候，先去消耗 k，没有 k 了，需要新青蛙，ans 加 1。

如果字母的数量在中间出现了小于0的情况，那么就说明有不符合顺序的字母出现，那么就是错误叫声返回-1

如果最后字母的数量不是0，说明有问题，返回-1

## **Python3**

<!-- 这里可写当前语言的特殊实现逻辑 -->

```python
class Solution:
    def minNumberOfFrogs(self, croakOfFrogs: str) -> int:
        c = r = o = a = k = ans = 0
        for ch in croakOfFrogs:
            if ch == 'c':
                c += 1
                if k > 0:
                    k -= 1
                else:
                    ans += 1
            elif ch == 'r':
                r += 1
                c -= 1
            elif ch == 'o':
                o += 1
                r -= 1
            elif ch == 'a':
                a += 1
                o -= 1
            else:
                k += 1
                a -= 1
            if c < 0 or r < 0 or o < 0 or a < 0:
                return -1
        return -1 if c != 0 or r != 0 or o != 0 or a != 0 else ans
```

class Solution {
    public int minNumberOfFrogs(String croakOfFrogs) {

                }

                --r;
            } else if (ch == 'a') {
                ++a;
                --o;
            } else {
                ++k;
                --a;
            }
            if (c < 0 || r < 0 || o < 0 || a < 0) {
                return -1;
            }
        }
        return c == 0 && r == 0 && o == 0 && a == 0 ? ans : -1;

# 解法2（官方）

## 思路
leetcode官方思路

一个青蛙想发出蛙鸣，需要依次输出五个字符，输出`c`开始蛙鸣，输出`k`结束蛙鸣
使用`frog_num` 表示正在发出蛙鸣的青蛙数量，`cnt[x]`（$x\in[0,3]$）表示正在发出一次有效字符`c/r/o/a` 的青蛙数量。使用`res` 正在发出蛙鸣的青蛙数量最大值。

遍历输入字符串`croakOfFrogs`，正在遍历的字符记为`ch`

- 若`ch=c` ，那么说明有一只青蛙开始蛙鸣，青蛙数量+1，正在发出`c` 的青蛙数量+1， `frog_num=frog_num+1` ,`cnt[c]=cnt[c]+1`，如果此时青蛙数量大于`res`，则把值赋给`res`
- 若`ch!=c`, 那么正在发出的当前字符对应的前一个字符（croak中）的青蛙数量为 `cnt[ch-1]` ,比如当前字符是`k`，那么在croak中前一个字符就是`a`， 
	- `cnt[ch-1]==0` ,则说明之前没有正在发出一次有效前序字符 的青蛙，那么当前字符还不是`c`，有错误，返回-1，比如当前字符是`k`，但是正在发出`a` 的青蛙数量为0，那肯定是有错。
	- `cnt[ch-1]!=0`,则说明之前有正在发出一次有效前序字符的青蛙，那么这只青蛙就从正在发出前序字符转变为正在发出当前字符或者结束蛙鸣（当正在发出的音符是`k` 时），`cnt[ch-1]-=1`, `cnt[ch]+=1`/`frog_num-=1` 

如果遍历完字符串，还有正在发出蛙鸣的青蛙，那么说明有问题，返回-1，最后返回同时在发出蛙鸣的青蛙数量`res`

## python


```python
class Solution:
    def minNumberOfFrogs(self, croakOfFrogs: str) -> int:
        if len(croakOfFrogs) % 5:
            return -1
        res, frog_num = 0, 0
        cnt = [0] * 4
        mp = {'c':0, 'r':1, 'o':2, 'a':3, 'k':4}
        for ch in croakOfFrogs:
            t = mp[ch]
            if t == 0:
                cnt[t] += 1
                frog_num += 1
                if frog_num > res:
                    res = frog_num
            else:
                if cnt[t - 1] == 0:
                    return -1
                cnt[t - 1] -= 1
                if t == 4:
                    frog_num -= 1
                else:
                    cnt[t] += 1
        if frog_num > 0:
            return -1
        return res
```

class Solution {
    public int minNumberOfFrogs(String croakOfFrogs) {
        if (croakOfFrogs.length() % 5 != 0) {
            return -1;
        }
        int res = 0, frogNum = 0;
        int[] cnt = new int[4];
        Map<Character, Integer> map = new HashMap<Character, Integer>() {{
            put('c', 0);
            put('r', 1);
            put('o', 2);
            put('a', 3);
            put('k', 4);
        }};
        for (int i = 0; i < croakOfFrogs.length(); i++) {
            char c = croakOfFrogs.charAt(i);
            int t = map.get(c);
            if (t == 0) {
                cnt[t]++;
                frogNum++;
                if (frogNum > res) {
                    res = frogNum;
                }
            } else {
                if (cnt[t - 1] == 0) {
                    return -1;
                }
                cnt[t - 1]--;
                if (t == 4) {
                    frogNum--;
                } else {
                    cnt[t]++;
                }
            }
        }
        if (frogNum > 0) {
            return -1;
        }
        return res;
    }
}
