# 题目描述
你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你 **不触动警报装置的情况下** ，一夜之内能够偷窃到的最高金额。

**示例 1：**

**输入：**[1,2,3,1]
**输出：** 4
**解释：** 偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。

**示例 2：**

**输入：**[2,7,9,3,1]
**输出：** 12
**解释：** 偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。

**提示：**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

# 解法1 递归

## 思路
【动态规划入门：从记忆化搜索到递推】 https://www.bilibili.com/video/BV1Xj411K7oF/?share_source=copy_web&vd_source=2ed70aa47f48e7a6d8d91665c429a9dc

考虑第一个或者最后一个房子选还是不选，问题就变成n-1个房子，而相邻的房子不选，因此问题变成n-2个房子，就

回溯三问：
- 当前操作？枚举第i个房子选/不选
- 子问题？从前i个房子中的到的最大金额和
- 下一个子问题？分类讨论：
	- 不选：从前i-1个房子中得到最大金额和
	- 选：从前i-2个房子中得到最大金额和

$$dfs(i)=\max (dfs(i-1),dfs(i-2)+nums[i])$$
$dfs(i-1)$ 就是不选当前房子，$dfs(i-2)+nums[i]$ 就是选房前房子

因此可以写递归：
```python
class Solution(object):
    def rob(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        n = len(nums)
        def dfs(i):
            if i < 0:
                return 0
            res = max(dfs(i-1),dfs(i-2)+nums[i])
            return res
        return dfs(n-1)
```

但是实际上会超出时间限制，因为时间复杂度是指数级别的

所以可以记忆化搜索，把递归的计算结果保存下来，如果递归到同样的入参，就可以直接返回先前保存的结果

递归搜索+保存计算结果=记忆化搜索

时间复杂度变为O（n）

对于python 可以用一个 `@cach` 装饰器，即用一个hash map记录入参和对应的返回值，
也可以用一个数组来储存

复杂度：状态个数×每个状态计算
## python


```python
class Solution(object):
    def rob(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        n = len(nums)
        cache = [-1] * n # 用一个数组储存结果
        def dfs(i):
            if i < 0:
                return 0
            if cache[i] != -1: # 如果有结果，则储存
                return cache[i]
            res = max(dfs(i-1),dfs(i-2)+nums[i])
            cache[i] = res # 数组记录结果
            return res
        return dfs(n-1)
```
