# 题目描述

给定一个含有 n 个正整数的数组和一个正整数 `s` ，找出该数组中满足其和 ≥ s 的长度最小的 连续 子数组，并返回其长度。如果不存在符合条件的子数组，返回 0。

示例：

- 输入：`s = 7, nums = [2,3,1,2,4,3]`
- 输出：`2`
- 解释：子数组 `[4,3]` 是该条件下的长度最小的子数组。

提示：

- 1 <= target <= 10^9
- 1 <= nums.length <= 10^5
- 1 <= nums[i] <= 10^5


# 解法1 滑动窗口

## 思路
用一个滑动窗口选定和结果大于s的数组

## python

这里需要注意的是，对于最小长度需要取`min(l,right-left+1)` 因为可能有多个窗口符合条件，此时需要找最小的，而`l`初始化需要设置为数组的和或者直接设置为无限大，设置为无限大的方法就是 `l= floar("inf")`

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        left,right = 0,0
        n = len(nums)
        min_sum = 0
        l = float('inf')
        while right < n:
            min_sum += nums[right]
            while min_sum >= target:
                l = min(l,right - left + 1)
                min_sum = min(min_sum, min_sum-nums[left])
                left += 1
            right += 1
        return l if l != float("inf") else 0
```
