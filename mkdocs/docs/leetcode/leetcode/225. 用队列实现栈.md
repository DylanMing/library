# 题目描述
请你仅使用两个队列实现一个后入先出（LIFO）的栈，并支持普通栈的全部四种操作（`push`、`top`、`pop` 和 `empty`）。

实现 `MyStack` 类：

- `void push(int x)` 将元素 x 压入栈顶。
- `int pop()` 移除并返回栈顶元素。
- `int top()` 返回栈顶元素。
- `boolean empty()` 如果栈是空的，返回 `true` ；否则，返回 `false` 。

**注意：**

- 你只能使用队列的标准操作 —— 也就是 `push to back`、`peek/pop from front`、`size` 和 `is empty` 这些操作。
- 你所使用的语言也许不支持队列。 你可以使用 list （列表）或者 deque（双端队列）来模拟一个队列 , 只要是标准的队列操作即可。

**示例：**

**输入：**
`["MyStack", "push", "push", "top", "pop", "empty"]`
`[[], [1], [2], [], [], []]`
**输出：**
`[null, null, null, 2, 2, false]`

**解释：**
MyStack myStack = new MyStack();
myStack.push(1);
myStack.push(2);
myStack.top(); // 返回 2
myStack.pop(); // 返回 2
myStack.empty(); // 返回 False

# 解法1 两个队列模拟栈

## 思路
和用队列实现栈类似，这里栈是先进后出，队列是先进先出，那么对于入栈元素， 123， 出栈顺序应该是 321， 而对于队列来说则是123，那么怎么实现呢，

可以用一个队列储存，另一个队列用于暂时存放，每次把除了最后一个元素之外的所有元素放出暂存队列，储存队列就能弹出最后一个入队的元素，再将暂存队列还原到储存队列，重复即可

注意这里使用deque，则实现先进先出删除时使用 `popleft*`
## python

需要注意的点：
- top后需要还原队列，此时还需要将`in_que` 里剩的加入`out_que` 再统一挪回去，否则顺序会乱
- pop时则不需要加剩的了，因为直接删掉了

```python
class MyStack(object):

    def __init__(self):
        self.in_que = collections.deque()
        self.out_que = collections.deque()

    def push(self, x):
        """
        :type x: int
        :rtype: None
        """
        self.in_que.append(x)


    def pop(self):
        """
        :rtype: int
        """
        if self.empty():
            return None
        for i in range(len(self.in_que)-1):
            self.out_que.append(self.in_que.popleft())
        x = self.in_que.popleft()
        for i in range(len(self.out_que)):
            self.in_que.append(self.out_que.popleft())
        return x


    def top(self):
        """
        :rtype: int
        """
        if self.empty():
            return None
        for i in range(len(self.in_que)-1):
            self.out_que.append(self.in_que.popleft())
        x = self.in_que[-1]
        self.out_que.append(self.in_que.popleft())
        for i in range(len(self.out_que)):
            self.in_que.append(self.out_que.popleft())
        return x


    def empty(self):
        """
        :rtype: bool
        """
        return not self.in_que



# Your MyStack object will be instantiated and called as such:
# obj = MyStack()
# obj.push(x)
# param_2 = obj.pop()
# param_3 = obj.top()
# param_4 = obj.empty()
```

# 解法2 一个队列模拟栈

## 思路

其实只需要将队列中n-1个元素弹出再加入即可

## python


```python
class MyStack(object):

    def __init__(self):
        self.q = collections.deque()

    def push(self, x):
        """
        :type x: int
        :rtype: None
        """
        self.q.append(x)
        


    def pop(self):
        """
        :rtype: int
        """
        if self.empty():
            return None
        for i in range(len(self.q)-1):
            self.push(self.q.popleft())
        return self.q.popleft()

    def top(self):
        """
        :rtype: int
        """
        if self.empty():
            return None
        for i in range(len(self.q)-1):
            self.push(self.q.popleft())
        x = self.q.popleft()
        self.push(x)
        return x


    def empty(self):
        """
        :rtype: bool
        """
        return not self.q



# Your MyStack object will be instantiated and called as such:
# obj = MyStack()
# obj.push(x)
# param_2 = obj.pop()
# param_3 = obj.top()
# param_4 = obj.empty()
```
