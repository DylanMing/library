# 题目描述
请你仅使用两个栈实现先入先出队列。队列应当支持一般队列支持的所有操作（`push`、`pop`、`peek`、`empty`）：

实现 `MyQueue` 类：

- `void push(int x)` 将元素 x 推到队列的末尾
- `int pop()` 从队列的*开头移除并返回元素*
- `int peek()` *返回队列开头的元素*
- `boolean empty()` 如果队列为空，返回 `true` ；否则，返回 `false`

**说明：**

- 你 **只能** 使用标准的栈操作 —— 也就是只有 `push to top`, `peek/pop from top`, `size`, 和 `is empty` 操作是合法的。
- 你所使用的语言也许不支持栈。你可以使用 list 或者 deque（双端队列）来模拟一个栈，只要是标准的栈操作即可。

# 解法1

## 思路 使用列表模拟栈


队列是先进先出，栈是先进后出


那么对于一个队列，其元素为 123（数字表示进入顺序），如果我们直接将其放进栈中，那么栈中的元素也为123，但是对于队列，我们出队的顺序是123，出栈的顺序是321

这时候就需要用两个栈来解决这个问题

所以我们构建两个栈：
- in
- out
将入栈的元素调换到出栈的的元素里，但是需要调换顺序，将in栈里的元素出栈则为321，加入到out栈里，那么out栈里的为321，再从out栈里出来就是123了，和队列一致


这里需要注意的是，出队列的时候才要使用out栈来排序，否则会让顺序错乱，（比如之前out栈里已有元素，此时再加则顺序不对）



## python
这里需要注意的点：
- pop时是用pop将in_stack中的元素删除并移到out_stack，如果不删除影响empty
- peek虽然只是返回开头的元素，但是实际上我们这里也用pop将in_stack中的元素删除并移到out_stack，因为



```python
class MyQueue(object):

    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        """
        :type x: int
        :rtype: None
        """
        self.in_stack.append(x)


    def pop(self):
        """
        :rtype: int
        """
        if self.empty():
            return None
        if self.out_stack: # 如果出栈铀元素，就删除出栈的最后一个元素即可
            return self.out_stack.pop()
        else: # 出栈如果是空，就先让进栈的元素移到出栈 
            for i in range(len(self.in_stack)):
                self.out_stack.append(self.in_stack.pop())
            return self.out_stack.pop()




    def peek(self):
        """
        :rtype: int
        """
        if self.empty():
            return None
        if self.out_stack:
            return self.out_stack[-1]
        else:
            for i in range(len(self.in_stack)):
                self.out_stack.append(self.in_stack.pop())
            return self.out_stack[-1]


    def empty(self):
        """
        :rtype: bool
         只要in或者out有元素，说明队列不为空
        """
        return not (self.in_stack or self.out_stack)

# obj.push(x)
# param_2 = obj.pop()
# param_3 = obj.peek()
# param_4 = obj.empty()
```
