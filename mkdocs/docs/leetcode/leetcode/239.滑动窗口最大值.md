# 题目描述

给定一个数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

返回滑动窗口中的最大值。

示例 1：

输入：`nums = [1,3,-1,-3,5,3,6,7], k = 3`
输出：`[3,3,5,5,6,7]`
解释：
滑动窗口的位置                最大值
---------------               -----
`[1  3  -1] -3  5  3  6  7       3`
 `1 [3  -1  -3] 5  3  6  7       3`
 `1  3 [-1  -3  5] 3  6  7       5`
 `1  3  -1 [-3  5  3] 6  7       5`
 `1  3  -1  -3 [5  3  6] 7       6`
 `1  3  -1  -3  5 [3  6  7]      7`
示例 2：

输入：`nums = [1], k = 1`
输出：`[1]`

进阶：

你能在线性时间复杂度内解决此题吗？
# 解法1 单调队列

## 思路

使用一个队列，只维护有可能成为窗口里最大值的元素，同时保证队列里的元素数值是由大到小的
比如，对于`nums: 13-1-35367 k=3`
那么第一个窗口 13-1，维护整个队列单调递减，我们删除所有前面较小的数，即队列加入3 -1， 因为1不是最大值没用
然后第二个窗口 3 -1 -3，维护整个队列单调递减， 此时最大值还是3，
第三个窗口 -1 -3 5， 维护整个队列单调递减，那么则删除 -1， -3， 最大值为5
第四个窗口 -3 5 3， 维护整个队列单调递减，那么加入3，最大值为5
第五个窗口 5 3 6， 维护整个队列单调递减，那么删除5， 3 ， 加入6 最大值为6
第七个窗口 3 6 7，维护整个队列单调递减，那么删除6，加入7，最大值为7



及时去掉无用数据，保证双端队列有序
- 当前数字>=对位，弹出队尾（单调栈）
- 弹出队首不在窗口内的元素

## python


```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        ans = []
        q = deque() #记录下标的队列
        for i,x in enumerate(nums):
            # 进入窗口
            while q and nums[q[-1]] <= x: # 队列最后一个元素小于等于x，则需要弹出
                q.pop()
            q.append(i)
            # 出
            if i - q[0] >= k: # 队首元素已经不在窗口内了
                q.popleft()
            # 记录答案
            if i >= k-1:
                ans.append(nums[q[0]]) # 队首是最大值
        return ans

```
