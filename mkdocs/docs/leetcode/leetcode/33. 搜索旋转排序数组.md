# 题目描述
整数数组 `nums` 按升序排列，数组中的值 **互不相同** 。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了 **旋转**，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标 **从 0 开始** 计数）。例如， `[0,1,2,4,5,6,7]` 在下标 `3` 处经旋转后可能变为 `[4,5,6,7,0,1,2]` 。

给你 **旋转后** 的数组 `nums` 和一个整数 `target` ，如果 `nums` 中存在这个目标值 `target` ，则返回它的下标，否则返回 `-1` 。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**

**输入：** nums = [`4,5,6,7,0,1,2]`, target = 0
**输出：** 4

**示例 2：**

**输入：** nums = [`4,5,6,7,0,1,2]`, target = 3
**输出：**-1

**示例 3：**

**输入：** nums = [1], target = 0
**输出：**-1

**提示：**

- `1 <= nums.length <= 5000`
- `-104 <= nums[i] <= 104`
- `nums` 中的每个值都 **独一无二**
- 题目数据保证 `nums` 在预先未知的某个下标上进行了旋转
- `-104 <= target <= 104`

# 解法1

## 思路 两次二分查找

第一次二分查找，参考[[153.寻找旋转排序数组中的最小值]],找到最小值，第二次二分查找对比target和最后一个数的大小，确定其在数组的哪个部分，然后再进行二分查找

```python
class Solution(object):
    def search(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """
        def findmin(nums):
            l, r = 0, len(nums)-1
            while l<r:
                mid = r + (l-r)//2
                if nums[mid]>nums[-1]:
                    l = mid + 1
                else:
                    r = mid
            return l
        
        def lower(nums,left,right,target):
            while left<right:
                mid = right+(left-right)//2
                if nums[mid]<target:
                    left = mid + 1
                else:
                    right = mid
            return left if nums[left] == target else -1
        
        i = findmin(nums)
        if target > nums[-1]:
            return lower(nums,0,i+1,target)
        return lower(nums,i,len(nums),target)
```
但是对于样例
`[1] 2` 报错了数组越界
实际上是上面查找的右边界写错了

# 解法2 一次二分查找

## 思路


不找到数组前后边界位置，那么直接利用单调性可不可以

直接分类型讨论，最后合并一下就行，注意是不是所有情况都讨论了，要不然会超时
## python

```python
class Solution(object):
    def search(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """     
        l,r = 0,len(nums)-1
        while l < r:
            mid = (l+r)//2
            m = nums[mid]
            if m == target:
                return mid
            elif m < target <= nums[-1] or nums[-1]< m < target or target <= nums[-1] < m :
                l = mid + 1
            else:
                r = mid - 1
        return l if nums[l] == target else -1
```

class Solution:
    def search(self, nums, target):
        if not nums:
            return -1
        l, r = 0, len(nums) - 1
        while l <= r:
            mid = (l + r) // 2
            if nums[mid] == target:
                return mid
            if nums[0] <= nums[mid]:
                if nums[0] <= target < nums[mid]:
                    r = mid - 1
                else:
                    l = mid + 1
            else:
                if nums[mid] < target <= nums[len(nums) - 1]:
                    l = mid + 1
                else:
                    r = mid - 1
        return -1
