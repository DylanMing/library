# 题目描述
给你一个整数数组 `nums` 和一个整数 `k` ，请你返回其中出现频率前 `k` 高的元素。你可以按 **任意顺序** 返回答案

示例 1:

输入: `nums = [1,1,1,2,2,3], k = 2`
输出: `[1,2]`

示例 2:

输入: `nums = [1], k = 1`
输出: `[1]`
 

提示：

1 <= nums.length <= 105
k 的取值范围是 `[1, 数组中不相同的元素的个数]`
题目数据保证答案唯一，换句话说，数组中前 k 个高频元素的集合是唯一的
 

进阶：你所设计算法的时间复杂度 必须 优于 O(n log n) ，其中 n 是数组大小。


首先我们将其拆解为两个子问题：
- 求元素的频率
- 按照频率排序

元素的频率可以通过hashmap保存，key是元素，value是次数
频率排序则使用优先级队列（快排是nlogn,我们只需要维护前k个不需要）

大顶堆就是根节点最大，小顶堆就是根节点最小，实现都是二叉树

维护时使用小顶堆，每次推出堆顶，复杂度时nlogk
# 解法1 

## 思路

使用字典计算频率，get可以返回值，没有key就返回给定值（0）

使用heapq包来构建小顶堆，heappush可以添加元素，heappop删除元素，维护k大小的小顶堆即可
## python

```python

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        map = {}
        for num in nums:
            map[num] = map.get(num,0) + 1
        print(map)
        heap = []
        for key,v in map.items():
            heappush(heap,(v,key))  # 推入当前值
            if len(heap) > k:
                heappop(heap) # 堆顶删除
        print(heap)
        return [x[1] for x in heap]
```
