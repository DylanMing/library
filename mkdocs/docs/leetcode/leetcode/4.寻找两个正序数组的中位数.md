# 题目描述

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))` 。

**示例 1：**

**输入：** nums1 = [1,3], nums2 = [2]
**输出：** 2.00000
**解释：** 合并数组 = [1,2,3] ，中位数 2

**示例 2：**

**输入：** nums1 = [1,2], nums2 = [3,4]
**输出：** 2.50000
**解释：** 合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5

**提示：**

- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-106 <= nums1[i], nums2[i] <= 106`

## 思路

要求算法的时间复杂度应该为 `O(log (m+n))` 。那么就是二分查找

如果m+n是奇数，那么中位数是数组中的数，如果m+n是偶数，那么中位数就是两个数的平均值

`l1, l2 = len(nums1), len(nums2)` 总长度为 `l = l1+l2` 
 - `l` 是奇数的情况， 那么中位数就是第 `(l+1)//2`大的数，
 - `l` 是偶数的情况， 那么中位数就是第 `l//2`大的数，和 `l//2+1`大的数的平均值
 所以可以先定义一个函数 `getkth`找到第`k`个大的数，假设中位数就是第`k`个数

我们可以直接查找两个数组的中位数，也就是`nums1[k/2]` 和 `nums2[k/2]` 然后比较这两个数的大小，
这两个数前面一共有`k-2`个数 分别比他们都小，也就是说前面的数都不可能是中位数，因此排除，
然后比较这两个数
