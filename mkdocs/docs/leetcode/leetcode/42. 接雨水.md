# 题目描述
给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。
![[Pasted image 20240821111115.png]]

**输入：** `height = [0,1,0,2,1,0,1,3,2,1,2,1]`
**输出：** 6
**解释：** 上面是由数组 `[0,1,0,2,1,0,1,3,2,1,2,1]` 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。 

**示例 2：**

**输入：** `height = [4,2,0,3,2,5]`
**输出：** 9


每个柱子的雨水高度-柱子高度就是这个柱子的雨水量，关键是求每个柱子的雨水高度
可以看到柱子的雨水高度是和左右两边的短板有关系的，这个和[[11.盛水最多的容器]]类似
所以其实也可以用双向指针做，但是需要求的是每个柱子的雨水高度，

# 解法1 前后缀

## 思路
前后缀分解，维护**前后缀数组**，前缀为左侧和当前高度的最大值，后缀为右侧和当前高度的最大值，求雨水面积时取前后缀中小的作为短板。雨水面积为 短板-当前高度
看看怎么合并循环
## python

```python
class Solution(object):
    def trap(self, height):
        """
        :type height: List[int]
        :rtype: int
        """
        n = len(height)
        ans = pre = suf = l = 0
        r = n-1
        while l<r:
            pre = max(pre,height[l])
            suf = max(suf,height[r])
            if pre<suf:
                ans += pre - height[l]
                l += 1
            else:
                ans += suf -height[r]
                r -= 1
        return ans
        

```

# 解法2 双向指针

## 思路
和盛水容器类似，双向指针遍历，
从前后缀的角度来说，就是用变量替代前后缀数组，每次计算出雨水最低面积就可以更新下一个柱子了

## python
