# 题目描述
给定方法 `rand7` 可生成 `[1,7]` 范围内的均匀随机整数，试写一个方法 `rand10` 生成 `[1,10]` 范围内的均匀随机整数。

你只能调用 `rand7()` 且不能调用其他方法。请不要使用系统的 `Math.random()` 方法。

每个测试用例将有一个内部参数 `n`，即你实现的函数 `rand10()` 在测试时将被调用的次数。请注意，这不是传递给 `rand10()` 的参数。

**示例 1:**

**输入:** `1`
**输出:** `[2]`

**示例 2:**

**输入:** `2`
**输出:** `[2,8]`

**示例 3:**

**输入:** `3`
**输出:** `[3,8,10]`

# 解法1  拒绝采样

## 思路

一个朴素的想法就是，通过两个 `rand7()` 的组合来生成`rand10()`，但是两个 `rand7()` 生成的范围是 `[1,14]` 我们想要的范围是 `[1,10]` 因此需要丢弃一些情况，也就是拒绝采样。


比如对于 `rand7()` 我们想生成 $x\in[1,5]$ ，可以不可以直接生成6，7的时候重新生成呢？
下面是证明：
对于某一个确定的x，（比如x=1），第一次就生成了x, 那么概率是 $\frac{5}{7}\times\frac{1}{5}=\frac{1}{7}$ ， 第二次生成x的概率是$\frac{2}{7}\times\frac{1}{7}$ ,这里的$\frac{1}{7}$ 就是第一种情况，递推可得总概率：
$$\begin{aligned}
&\frac{1}{7}+\frac{2}{7}\cdot\frac{1}{7}+(\frac{2}{7})^{2}\cdot\frac{1}{7}+\dots+(\frac{2}{7})^{n-1}\cdot\frac{1}{7}\\
=&\frac{1}{7}(1+\frac{2}{7}+\dots+(\frac{2}{7})^{n-1})\\
	=&\frac{1}{7}\cdot \frac{1-(\frac{2}{7})^{n}}{1-\frac{2}{7}}\\
	=& \frac{1}{7}\cdot \frac{1-(\frac{2}{7})^{n}}{\frac{5}{7}}\\
	= &\frac{1-(\frac{2}{7})^{n}}{5}\\
\approx& \frac{1}{5}
\end{aligned}$$


因此，这种拒绝生成重新采样得概率是 $\frac{1}{5}$

这样我们得到了 `rand5()` 可以随机生成 `[1,5]` , 再来一个`[1,5]` 就可以了，如果我们直接再相加，，反而得不到1，因此我们将第二部分设置如下：
如果生成4，则重新生成，如果小于4，则设置为0，如果大于4，则设置为5，这样就得到了一个函数，一半概率生成0，一半概率生成5，那么生成`[1,5]` 的概率就是 $\frac{1}{2}$ ，生成`[6,10]` 的概率也是$\frac{1}{2}$，最后就得到了 `rand10()`
 



## python


```python
# The rand7() API is already defined for you.
# def rand7():
# @return a random integer in the range 1 to 7

class Solution:
    def rand10(self):
        """
        :rtype: int
        """
        n = rand7()
        while n > 5: # 大于5则重新生成，
            n = rand7()
        i = rand7()
        while i == 4: # 等于4则重新生成
            i = rand7()
        if i < 4: # 小于4
            j = 0
        else:
            j = 5
        return n+j
```
