# 题目描述

给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

**示例 1:**

> **输入:** strs = `["eat", "tea", "tan", "ate", "nat", "bat"]`
> **输出:** `[["bat"],["nat","tan"],["ate","eat","tea"]]`

**示例 2:**

> **输入:** strs = `[""]`
> **输出:** `[[""]]`

**示例 3:**

**输入:** strs = `["a"]`
**输出:** `[["a"]]`

**提示：**

- `1 <= strs.length <= 104`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母
# 解法1  排序后作为key，list作为value

对于不同排列的字母，想法是将其排序后应该得到相同的排列，字母异位词应该对应相同的排列，那么就变成查找具有相同排列的单词。查找上使用hashtable（字典即可）。而字典的值可以是我们需要返回的列表，将有相同排列的单词加入到对应key（排列）的value（列表）里

```python
class Solution:
	def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
		dict = collections.defaultdict(list)
		for i in strs:
			key = "".join(sorted(i))
			dict[key].append(i)
		return list(dict.values())
```

这里用defaultdict是因为默认为List的空列表也可以返回，其实可以通过一个简单的if判断是否已经存在key来避免空列表（而且比用defaultdict快）

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        dict = {}
        for i in strs:
            key = "".join(sorted(i))
            if key in dict:
                dict[key].append(i)
            else:
                dict[key] = []
                dict[key].append(i)  
        return list(dict.values())
```
