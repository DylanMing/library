# 解法1 双指针切片

## 思路
通过双指针每次移动2k，第一个指针标记当前块，第二个指针标记k处反转，通过切片来反转字符串

## python

```python
class Solution:
    def reverseStr(self, s: str, k: int) -> str:
        p = 0
        while p < len(s):
            p2 = p + k
            s = s[:p] + s[p: p2][::-1] + s[p2:]
            p = p + 2 * k
        return s

```
