# 题目描述

给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 _该数组中和为 `k` 的子数组的个数_ 。

子数组是数组中元素的连续非空序列。

**示例 1：**

**输入：**nums = [1,1,1], k = 2
**输出：**2

**示例 2：**

**输入：**nums = [1,2,3], k = 3
**输出：**2

**提示：**

- `1 <= nums.length <= 2 * 104`
- `-1000 <= nums[i] <= 1000`
- `-107 <= k <= 107`


需要注意的是，这里的子数组是连续的，不能是在数组中随机抽取的，要不然就不能用前缀和了

# 解法1 前缀和遍历


## 思路
利用前缀和，计算和为 $k$ 的子数组。前缀和通过`s` 数组保存，那么就需要找到所有的`sj`-`si`=`k` 的所有子数组，其实就转变成了两数之和，找到所有的$sj+(-si)=k$ 的组合。

## python

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
    s = [0]*(len(nums)+1) # 初始化前缀和数组，初始化时需要s0=0，因此需要初始化长度 len(nums)+1
    for i, v in enumerate(nums):
		s[i+1] = s[i]+v # 前缀和计算，s0=0，从s1计算到sn
	ans = 0
	cnt = defaultdict(int)
	for sj,value in enumerate(s):
		ans += cnt[sj-k] # 哈希表中查找sj-k的数量
		cnt[sj] += 1 # 将当前sj加入到哈希表中
	return ans

```



# 解法2 一次遍历，一边计算前缀和，一边遍历前缀和

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        # 一次遍历，一边计算前缀和，一边遍历前缀和
        s = ans = 0
        cnt = defaultdict(int)
        cnt[0] = 1  # 初始化，前缀和为0的情况
        for v in nums:
            s += v  # 计算当前前缀和
            # 查找是否存在前缀和为(prefix_sum - k)
            ans += cnt[s - k]
            # 将当前前缀和加入哈希表
            cnt[s] += 1
            
        return ans
```

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        ans = s = 0
        cnt = defaultdict(int)
        for x in nums:
            cnt[s] += 1
            s += x
            ans += cnt[s - k]
        return ans
```
