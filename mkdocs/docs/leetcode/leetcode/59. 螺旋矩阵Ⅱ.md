# 题目描述
给你一个正整数 `n` ，生成一个包含 `1` 到 `n2` 所有元素，且元素按顺时针顺序螺旋排列的 `n x n` 正方形矩阵 `matrix` 。
**输入：** `n = 3`
**输出：** `[[1,2,3],[8,9,4],[7,6,5]]`

**示例 2：**

**输入：** `n = 1`
**输出：** `[[1]]`
# 解法1

## 思路
其实就是二维数组的存取，需要注意的是按照边的规则来进行循环赋值，需要注意区间左闭右开，这个可以通过range实现，range就是左闭右开的，同时需要注意更新上下左右的边界条件，最后一个需要注意的点是对于切片的时候，竖着的部分需要循环在前

## python


```python
class Solution:
    def generateMatrix(self, n: int) -> [[int]]:
        mat = [[0]*n for _ in range(n)]
        # mat = [[0 for _ in range(n)] for _ in range(n)]
        l,r,t,b = 0, n-1,0,n-1
        num,tar = 1, n*n
        while num <= tar:
            for i in range(l,r+1): # range 本身就是左闭右开的
                mat[t][i] = num
                num += 1
            t += 1
            for i in range(t,b+1):
                mat[i][r] = num # 这里注意i在前
                num += 1
            r -= 1
            for i in range(r, l-1, -1):
                mat[b][i] = num
                num += 1
            b -= 1
            for i in range(b, t-1, -1):
                mat[i][l] = num
                num += 1
            l += 1
        return mat
```
