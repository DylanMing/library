# 题目描述

给你一个按 **非递减顺序** 排序的整数数组 `nums`，返回 **每个数字的平方** 组成的新数组，要求也按 **非递减顺序** 排序。

**示例 1：**

**输入：** `nums = [-4,-1,0,3,10]`
**输出：**`[0,1,9,16,100]`
**解释：** 平方后，数组变为 `[16,1,0,9,100]`
排序后，数组变为 `[0,1,9,16,100]`

**示例 2：**

**输入：**`nums = [-7,-3,2,3,11]`
**输出：**`[4,9,9,49,121]`

**提示：**

- `1 <= nums.length <= 104`
- `-104 <= nums[i] <= 104`
- `nums` 已按 **非递减顺序** 排序

**进阶：**

- 请你设计时间复杂度为 `O(n)` 的算法解决本问题
# 解法1 左右双指针

## 思路

数组本来是排序好的，但是因为负数的平方可能会大于正数的平方，所以顺序可能有问题，但是可以知道的是还是有顺序的，最大的一定是数组两端的数，因此使用左右双指针，从数组两端向中间扫，哪边大就加入到新数组的末尾

## python

```python
class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        # 双指针，两头向中间扫，来判定负数的平方是否最大
        i,l,r = len(nums)-1, 0, len(nums)-1
        ans = [0] * len(nums)
        while l <= r:
            if nums[l]**2 < nums[r]**2:
                ans[i] = nums[r]**2
                r -= 1
            else:
                ans[i] = nums[l]**2
                l += 1
            i -= 1
        return ans
```
