二分查找主要思想就是通过区间的中间值对比，判断目标值在左半区间还是右半区间，那么就将区间缩小一半，复杂度`O(log n)` 。

二分的本质并非“单调性”，而是“**边界**”，只要找到某种性质，使得整个区间一分为二，那么就可以用二分把边界点二分出来。
# 二分查找的基本原理
其实就是通过缩小搜索区间，每次考中点值和target对比来缩小，最后让mid=l=r，最后是不是target另说（

通过*每次更改边界条件*，*确定新的搜索空间*，*通过循环条件控制遍历整个区间* 

需要注意的是 初始边界条件，循环条件和迭代边界条件的选择，最容易出现的问题就是 因为每次更改的边界条件和循环条件不匹配，导致陷入死循环。

这里有两个bisect，right就是找靠右的值，left就是找靠左的值，因为这里没有写`target==nums[mid]` 的情况，所以都是放在else里，else是左边界移动就是查右边的值，else是右边界移动就是查左边的值。
 
```python
def bisect_right(a, x, lo=0, hi=None, *, key=None):
    """Return the index where to insert item x in list a, assuming a is sorted.

    The return value i is such that all e in a[:i] have e <= x, and all e in
    a[i:] have e > x.  So if x already appears in the list, a.insert(i, x) will
    insert just after the rightmost x already there.

    Optional args lo (default 0) and hi (default len(a)) bound the
    slice of a to be searched.
    """

    if lo < 0:
        raise ValueError('lo must be non-negative')
    if hi is None:
        hi = len(a)
    # Note, the comparison uses "<" to match the
    # __lt__() logic in list.sort() and in heapq.
    if key is None:
        while lo < hi:
            mid = (lo + hi) // 2
            if x < a[mid]:
                hi = mid
            else:
                lo = mid + 1
    else:
        while lo < hi:
            mid = (lo + hi) // 2
            if x < key(a[mid]):
                hi = mid
            else:
                lo = mid + 1
    return lo

def bisect_left(a, x, lo=0, hi=None, *, key=None):

    insert just before the leftmost x already there.

    Optional args lo (default 0) and hi (default len(a)) bound the
    slice of a to be searched.
    """

    # __lt__() logic in list.sort() and in heapq.

            if a[mid] < x:
                lo = mid + 1
            else:
                hi = mid
    else:
```

```python
def bisect_left(arr:list[], target:int, left=0, right=None):
	if len(arr) == 0:
		return False
	if left<0:
		return False
	else right = None:
		right = len(arr)
	while left < right:
		mid = left+(right-left)//2 # 防止数值过大，+溢出
		if target > arr[mid]:
			left = mid + 1
		else: 
			right = mid
	return left
```

```python
# 闭区间写法
def lower_bound(nums: List[int], target: int) -> int:
    left, right = 0, len(nums) - 1  # 闭区间 [left, right]
    while left <= right:  # 区间不为空
        # 循环不变量：
        # nums[left-1] < target
        # nums[right+1] >= target
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1  # 范围缩小到 [mid+1, right]
        else:
            right = mid - 1  # 范围缩小到 [left, mid-1]
    return left

# 左闭右开区间写法
def lower_bound2(nums: List[int], target: int) -> int:
```

## 闭区间写法
- **边界条件**：因为是闭区间，搜索时包括两边边界，所以初始搜索边界就是数组的两边，即`0`， `len(nums)-1`
- **循环条件**：因为是闭区间，所以需要保证搜索时包括整个区间，而且left=right后的下一步跳出循环，因此`while l<= r`
- **更新条件**：这里就都默认向左查找，那么对于闭区间，因为刚才搜索过了前面的边界，所以要在原来的边界下再移动1，同时为了保证能跳出循环条件，所以 `l=mid+1` 和 `r=mid-1`


关键就是这三个条件

这里是左闭右开区间写法 即 `[  )`，也就是每次判定的时候，考虑`left=taget`的情况，而不考虑 `right = target`的情况，那么`left=right`时区间是空的，也就是说left=right时循环已经结束了，因此 `while left<right:` 是没有等号的

而`left=mid+1` 将区间缩小到 `[mid+1, right)` 
`right = mid`  将区间缩小到 `[left, mid）`

开闭区间是和边界条件相对应的，如果是闭区间，那么，在边界条件设定的时候就要注意+1，如果是开区间，那么就不用+1。而且*需要注意初始值的边界条件防止数组越界*。

关键点：假设待搜索区间为数组 `arr` 
1. 如果初始化右值 `r = len(arr)-1` ，那么*初始右边界为最后一个元素的索引*，*因此需要考虑该值*，所以应该是闭区间 `[l, r]` , 所以循环条件设置为 `while l <= r:` , 表示闭区间。考虑 `[l, r]`的情况，而每次赋值则需要 
   - `l = mid +1` ，此时搜索区间 `[mid+1, r]`, 因为闭区间 `[l,mid]`
   - `r = mid - 1`, 此时搜索区间为 `[l, mid-1]`,
    因为闭区间其实已经考虑了 `[mid, right]` 和 `[left,mid]` 的情况，
2. 如果初始化右值 `r = len(arr)` , 那么其为*初始右边界为最后一个元素的索引+1，因此不考虑该值*，所以应该是开区间 `[l,r)`， 所以循环条件设置为 `while l < r :` , 表示开区间，考虑 `[l, r)` 的情况，所以每次左值其实计算了，因此更新左值时需要 `l = mid + 1`



# 常见错误

## 循环条件，边界条件，死循环

二分查找的一个常见错误是陷入死循环，因为边界条件更新和循环条件的不匹配，容易出现死循环的情况


```python
class Solution(object):
    def searchInsert(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """
        l,r = 0, len(nums)
        while l <= r:
            mid = r + (l-r)//2
            if nums[mid] < target:
                l = mid + 1
            else:
                r = mid
        return l
```

对于测试样例 `nums = [1,3,5,6]`, `target = 5` 这里就是一个死循环，因为 `r` 初始化为 `len(nums)` ，`l` 初始化为`0`，  那么就要左闭右开区间进行搜索，但是while的循环判断为 `l<=r` ，那么搜索区间是闭区间，

`l=0,r=4,mid=2,nums[mid]=5=5,r=mid=2`
`l=0,r=2,mid=1,nums[mid]=3<5,l=mid+1=2`
`l=2,r=2,mid=2,nums[mid]=5=5,r=mid=2` 开始死循环

此时只需要将while循环里的等号去除就行，因为这个循环其实是找到了最后答案，但是没有返回而已

## 数组越界

有的人可能回想，elif 找到就返回不就行了吗，但是这样就会引起数组越界

```python
class Solution(object):
    def searchInsert(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """
        l,r = 0, len(nums)
        while l <= r:
            mid = r + (l-r)//2
            if nums[mid] < target:
                l = mid + 1
            elif nums[mid] == target:
	            return mid
            else:
                r = mid
        return l
```

对于用例 `nums = [1,3,5,6],target = 7` 最后就会数组越界，

`l=0,r=4,mid=2,nums[mid]=5<7,l=mid+1=3`

`l=4,r=4,mid=4,nums[mid]=6<7,l=mid+1=5` 数组越界
