# 并查集

## 什么是并查集

并查集，union-find/disjoint set，实际上是解决图的动态连通性问题，也被用来代替一些DFS，需要将问题转化为连通性问题

并查集其实是一种*树形的数据结构*，它的特点是*由子节点找到父亲节点*(查)，用于处理一些不交集的合并以及查询问题


并查集顾名思义分为**并**和**查**：

- **Find**：*确定元素属于哪一个子集*，被用来确定两个元素是否属于同一子集

- **Union**：*将两个子集合并成同一个集合*

实际上并查集还有两个操作：

- *添加新集合*

- *检查两个集合是否不相交*

# 一个例子 社交网络

一群人互相是朋友，那么我们可以按照朋友关系把他们分成不同的组,需要实现以下功能：

- 添加新的朋友关系，即人x和y成为朋友，*即向集合中添加新元素*

- 查找x和y是否是朋友（或间接朋友）


假设有10个人 `a, b, c, d, e, f, g, h, i, j`

有以下朋友关系

```
a <-> b    
b <-> d  
c <-> f  
c <-> i  
j <-> e  
g <-> j
```

那么我们可以分成
```python
G1 = {a, b, d}  
G2 = {c, f, i}  
G3 = {e, g, j}  
G4 = {h}
```

这些集合互不相交，就称为 并查集/不相交集

为了实现我们的功能，需要考虑关键点：

- **如何解决集合** 最初，所有的元素都属于不同的集合，在处理给定的关系后，选择一个成员作为代表，
- **检查两个成员是否在一个集合内** 如果两个成员的代表是同一个，就在一个集合内


使用的数据结构：

- 数组： parent数组，用来储存所有待处理元素的‘代表’, 而这些关系可以构建一个或多个树
- 树：并查集的格式以树表示，如果两个元素在同一个树中，那么就在同一个并查集中，并且树的根节点还可以表示这个集的代表。怎样验证一个元素是不是代表，可以通过 `parent[i] == i` 来验证，即自己可以代表自己，如果不是就可以通过对树的向上遍历来实现。


```python
# parent 数组的初始化
parent = defaultdict(int)
for i in range(len(M)):
    parent[i] = i # i的爸爸是他自己
```

# 基本操作: 查和并

## 查

查实际上就是**找到对应元素的根节点** ，并操作需要调用查，

这个可以通过一个简单的递归来完成

```python
def find(i,parent):
	if parent[i] == i: # 当前元素是根节点
		return i
	else: # 当前元素不是根节点， 那就验证其根节点是不是集合的根节点
		find(parent[i]) 
```

也可以通过循环来实现

```python
# 查根
def find(x, parent):
    r = x # r是个指针，表示处理的当前节点
    while r != parent[r]: # 当前元素不是根节点，需要寻找根节点
        r = parent[r] # 指针移到元素的父节点，
    return r # 循环结束时，指针指向的就是根节点
```


## 并

并操作需要输入两个元素，使用查找到他们的根节点，最后将其中一方的根节点放在另一方的根节点下，这样就完成了两个树（集合）的合并


```python
def union(x,y,parent):
	xrep,yrep = find(x,parent),find(y,parent)
	parent[xrep] = yrep
```


## 查找：路径压缩优化

可以通过压缩树的高度来优化速度，可以直接在查中将目标元素的代表赋值为集合的根节点，使得树的深度变为1，减少递归次数
类似动态规划把结果存下来

```python
def find(i,parent):
	if parent[i] == i:
		return i
	else:
		result = find(parent[i])
		parent[i] = result
		return result
```


## 合并：按排序合并和按大小合并

合并的时候有个问题，选择哪个元素作为合并后的集合的根节点，可以按照整个树的排序或者大小合并，具体做法是维护一个 `rank` 数组或者 `size`数组，合并时，将低排序合并到高排序上，或者将小集合合并到大集合上


```python
# Python3 program to implement Disjoint Set Data 
# Structure. 

class DisjSet: 
	def __init__(self, n): 
		# Constructor to create and 
		# initialize sets of n items 
		self.rank = [1] * n 
		self.parent = [i for i in range(n)] 


	# Finds set of given item x 
	def find(self, x): 
		
		# Finds the representative of the set 
		# that x is an element of 
		if (self.parent[x] != x): 
			
			# if x is not the parent of itself 
			# Then x is not the representative of 
			# its set, 
			self.parent[x] = self.find(self.parent[x]) 
			
			# so we recursively call Find on its parent 
			# and move i's node directly under the 
			# representative of this set 

		return self.parent[x] 


	# Do union of two sets represented 
	# by x and y. 
	def Union(self, x, y): 
		
		# Find current sets of x and y 
		xset = self.find(x) 
		yset = self.find(y) 

		# If they are already in same set 
		if xset == yset: 
			return

		# Put smaller ranked item under 
		# bigger ranked item if ranks are 
		# different 
		if self.rank[xset] < self.rank[yset]: 
			self.parent[xset] = yset 

		elif self.rank[xset] > self.rank[yset]: 
			self.parent[yset] = xset 

		# If ranks are same, then move y under 
		# x (doesn't matter which one goes where) 
		# and increment rank of x's tree 
		else: 
			self.parent[yset] = xset 
			self.rank[xset] = self.rank[xset] + 1

# Driver code 
obj = DisjSet(5) 
obj.Union(0, 2) 
obj.Union(4, 2) 
obj.Union(3, 1) 
if obj.find(4) == obj.find(0): 
	print('Yes') 
else: 
	print('No') 
if obj.find(1) == obj.find(0): 
	print('Yes') 
else: 
	print('No') 

# This code is contributed by ng24_7. 

```

## 并查集模板

- `n` 表示节点数
- `p` 存储每个点的父节点，初始时每个点的父节点都是自己
- `size` 只有当节点是祖宗节点时才有意义，表示祖宗节点所在集合中，点的数量
- `find(x)` 函数用于查找 x 所在集合的祖宗节点
- `union(a, b)` 函数用于合并 a 和 b 所在的集合

```python
p = list(range(n))
size = [1] * n

def find(x):
    if p[x] != x: # 
        # 路径压缩
        p[x] = find(p[x])
    return p[x]


def union(a, b):
    pa, pb = find(a), find(b)
    if pa == pb:
        return
    p[pa] = pb
    size[pb] += size[pa]
```
